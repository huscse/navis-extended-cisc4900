# NAVIS — Capstone Extension (CISC 4900)

### Independent Extension of NAVIS (Break Through Tech AI Studio, Fall 2025)

This repository contains my independent capstone extension of **NAVIS — Vision-Language Multimodal Dataset Navigator**, originally developed during the Break Through Tech AI Studio program in collaboration with Latitude AI (Ford).

The original project introduced an AI-powered semantic search engine for autonomous driving datasets using CLIP embeddings, FAISS vector search, and BLIP captioning.

This capstone extension focuses specifically on:

- Improving embedding and retrieval performance
- Optimizing vector indexing and search latency
- Enhancing hybrid semantic + metadata filtering
- Refining backend architecture for modularity and scalability
- Improving UI clarity and search usability
- Establishing measurable evaluation benchmarks

This repository represents new development, refinement, and experimentation conducted independently for CISC 4900.

This repository does **not** rebuild NAVIS from scratch.
Instead, it extends and improves the system’s AI-driven indexing, retrieval mechanisms, and usability to demonstrate measurable architectural and performance enhancements.
